# 事故记录：数据上传时设备掉电重启与缓存异常 (Brownout & Cache Error)

## 现象描述
设备在完成数据采集并等待 4G 模块驻网准备完毕后（含采集耗时约数十秒），在尝试上传数据的瞬间发生硬件崩溃。通过多次测试，捕获到两种不同表现的崩溃日志：

### 表现一：主控掉电复位
```text
I (9947) APP: [task_daq.c:110] Parallel 4G preparation: report_processing_overlap=681 ms, final_wait=5776 ms
E BOD: Brownout detector was triggered
```

### 表现二：4G模块死机重启与主控 Cache Error
```text
W (12199) APP: [drv_4g.c:1704] HTTP POST requestheader config failed:
RDY

W (12307) APP: [report_pipeline.c:824] Report JSON upload failed: ESP_FAIL
Guru Meditation Error: Core 0 panic'ed (Cache error).
```

## 软件流程跟踪与异常还原
经排查固件代码执行流程，确认软件逻辑正常。事发瞬间的完整崩溃证据链如下：

1. **并行初始化**：传感器采样完成后，主控并行启动 4G 模块上电与驻网。
2. **射频开启与模块饿死**：4G 网络就绪后，主控立即发送 AT 指令发起 HTTP POST。此时 4G 模块开始射频发射（RF TX），瞬间产生极大的瞬态峰值电流。该负载直接将 4G 模块自身的供电轨拉低至复位阈值以下，导致 **4G 模块自身瞬间死机并重启**（日志中紧接着失败提示打印出的 `RDY` 即为蜂窝模组上电重启就绪的标志符）。
3. **主控容错触发 Flash 操作**：ESP32-S3 发现 4G 上传失败，进入软件容错分支，调用 `report_pipeline_cache` 试图将本次数据存入内部 Flash（SPIFFS）以防丢失。
4. **主控断电与 Cache Error**：ESP32 在操作内部 Flash 时为了安全短暂关闭了指令和数据缓存（Cache Disabled）。此时，由于 4G 重载造成的电源电压仍处于严重的跌落状态，ESP32-S3 核心电压跌破掉电下限，触发了掉电检测中断（Brownout ISR）。
5. **双重打击导致 Panic**：由于 Cache 处于关闭状态，中断响应程序无法从 Flash 寻址并提取执行代码，抛出了致命的 `Cache error` 异常。

## 核心硬件原因：ER34615 电池选型与电容配置缺陷
经核实，当前硬件版本取消了第一版设计的超级电容，并且使用的是 **ER34615（锂亚硫酰氯能量型电池）** 直接或间接供电。这一改动在物理电学特性上存在致命冲突，是导致本次事故的绝对根本原因：

1. **ER34615 的严重内阻与钝化限制**：
   - ER34615 拥有极大容量和极低自放电，非常适合微安级休眠。但由于严重的钝化膜现象，其内阻极大。
   - 该类能量型电池的最大**连续放电电流通常仅在 150mA ~ 200mA**，即使是瞬间脉冲放电能力也仅在 **400mA** 左右。
2. **4G 模块的巨大瞬态需求**：
   - 4G 模块在发起 HTTP 数据传输的瞬间，射频天线需要的脉冲发射电流通常高达 **1500mA ~ 2000mA (1.5A - 2A)**。
3. **供需断层导致的物理崩盘**：
   - 强行让极限输出 400mA 的电池去带 2000mA 的负载，巨大的电池内阻会产生极高的压降（V = I * R），导致整个 3.3V 主电源轨瞬间被拉垮至 2V 甚至更低。这毫无悬念地造成了主控掉电（Brownout）和 4G 模块饿死断电重启。

## 硬件修复与整改建议（核心）
在物联网工程标准中，**绝对不可使用单节能量型 ER 电池直接驱动 4G/NB-IoT 蜂窝模组**。软件层面无法根治这种严重的物理缺口，必须在硬件层面予以纠正：

1. **加回超级电容/脉冲电容（强烈建议）**：
   - 必须恢复第一版设计的超级电容方案，采用标准的 **复合电源系统（ER + SPC/EPC）**（例如 ER34615 搭配 HPC1520 或 UPC1520 复合脉冲电容）。
   - **工作原理**：由超级电容充当“能量水库”。在 4G 发射的短短几秒内，由拥有极低内阻（ESR）的超级电容瞬间倾泻大电流扛下 2A 重载，从而稳住全局电压；平时待机时，则由 ER34615 电池以极小的安全电流缓慢为超级电容充电。
2. **若因结构或成本限制死活无法增加超级电容**：
   - 必须抛弃 ER34615，整体更换为内阻极小的 **动力型/高功率型电池**（如 CR 系列大电流电池或特殊定制的功率型锂亚电池）。
   - 同时必须在 4G 模块的 `VBAT` 供电管脚极近处，极其密集地堆叠大容量、极低 ESR 的高频钽电容阵列（例如并联多个大封装的 470uF/1000uF 低阻钽电容），以尽最大努力平抑电压跌落（但应对蜂窝脉冲的效果依然远逊于复合电容，且成本不一定低）。
